# pace-sample-shop

A small, made-up shop (customers, orders, billing, and a web client) used to
test [PACE](https://teamcentric.io). It is generated by PACE's
`scripts/sample_repo/generate.py`; regenerate it rather than editing it here.

It contains deliberate problems for PACE to find; see `AGENTS.md` and
`docs/adr/` for the rules they break.

## Run the tests

```bash
python -m pytest
```

`coverage/lcov.info` is a coverage report for PACE's coverage upload.
